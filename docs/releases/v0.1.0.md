# Paint.R 0.1.0 — initial git release

Status: initial internal development release of the Rust/egui implementation.
This is not a pixel-identical Paint.NET clone and does not load Paint.NET plugins.
It is not signed, notarized, or approved for public binary distribution.

## Highlights

- Native multi-document editor with per-tab paths, dirty markers, close guard,
  Save/Save As, Open and atomic PNG export.
- 19 Paint.NET tools in reference order, compact icon toolbar, contextual tool options,
  floating/docked Colors, Layers and History panels, grid/rulers/units and status bar.
- Mask-backed selections with Replace/Union/Subtract/Intersect/Xor and real-boundary
  marching ants.
- Live-preview raster tools, image operations, layer/blend operations, clipboard,
  New Image dialog, Edit selection actions, Effects/Adjustments, and macOS native menus.
- Deterministic headless trace/snapshot path and native macOS keyboard/dirty-close gate.

## Included parity batch

- Exact 19-tool toolbox and hotkeys.
- Move subpixel resampling (`Nearest Neighbor`, `Bilinear`, `Multisample Bilinear`,
  `Bicubic`; `Anisotropic` intentionally disabled until non-uniform scaling exists) and
  Enter/Finish for floating moves.
- New Image dialog, Select All, Invert Selection, Erase Selection, Fill Selection,
  Paste Into New Layer/Image.
- Fill/gradient/text/clone/recolor/picker tool-option parity for the implemented paths.
- Levels, Posterize, Black and White, Threshold adjustments with live previews.
- Panel default geometry, Layers footer, icon-only History/Colors actions, and status bar
  grouping aligned with the reference.

## Known gaps

See [UI_PARITY_DIFF.md](../reference/UI_PARITY_DIFF.md). In particular:

- Layers are not saved as a layered document; Save writes a flattened PNG.
- Curves, Exposure, Highlights and Shadows, Invert Alpha, Temperature and Tint remain
  intentionally disabled.
- Move has subpixel resampling but no scale/rotation handles; Freeform shapes are absent.
- Shape `Both` uses the primary color for the interior.
- OS clipboard and native-menu interaction are not fully exercised by headless tests.
- DPI/print/color-profile metadata is absent.
- No remote is configured in this checkout; the release tag is local until pushed.
