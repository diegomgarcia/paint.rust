# Paint.R 0.1.0 — initial git release

Status: initial internal development release from the Rust/egui implementation.
This is not a pixel-identical Paint.NET clone and does not load Paint.NET plugins.

## Highlights

- Native multi-document editor with per-tab paths, dirty markers, close guard, Save/Save As,
  Open and atomic PNG export.
- All 19 Paint.NET tool slots, compact icon toolbar, tool options, floating/docked Colors,
  Layers and History panels, grid/rulers/units, zoom and status bar.
- Mask-backed selections with combine modes and real-boundary marching ants.
- Raster paint tools with live previews, image operations, layers/blend modes, clipboard,
  effects/adjustments, and macOS native menus.
- Deterministic headless trace/snapshot path and native macOS keyboard/dirty-close gate.
