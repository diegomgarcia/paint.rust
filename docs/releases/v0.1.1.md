# Paint.Rust 0.1.1 — UI polish candidate

Status: released as `v0.1.1` (tag on `main`).

## Changes since v0.1.0

- Main toolbar follows CommonActionsStrip order with compact actions: New, Open, Save,
  Cut, Copy, Paste, Crop, Deselect, Undo, Redo, Grid, Rulers and Export.
- Contextual ToolConfigStrip reduced to one compact ~24 px row for all tools, with
  accessible combos, 24 px numeric fields, 16 px swatches, icon actions and separators.
- Inline canvas text editing with caret, live preview, Enter commit, Shift+Enter newline
  and Escape cancel; toolbar content field remains synchronized for accessibility.
- In-window File/Edit/View/Image/Layers menus use compact icon rows and actual shortcut
  hints; native macOS menu keeps native accelerators without icons.
- Layer edge-action enablement corrected; panel overlap with the tool strip fixed.
- Cmd+Plus/Cmd+Equals/Cmd+Minus now zoom only the document canvas; Cmd+0 returns to
  100%. egui's global UI zoom shortcut is disabled, so window chrome stays fixed.
- Save As now opens the native macOS/Windows/Linux file panel directly, with a **File type**
  popup inside the panel. It supports the complete `.pdr` session format, layered PDN and flat
  PNG, JPEG, TIFF, BMP, TGA, DDS, GIF and lossless WebP.
- Open now accepts every supported file type: PDR (restoring layers, selection and undo/redo
  history), PDN, and all eight flat raster formats. AVIF, HEIC, JPEG XL and
  JPEG XR remain unavailable until suitable codecs are bundled. Open remains PNG-only.

## Session and open-format work

- `.pdr` v1 stores the complete current document, all layers and selection state, and every
  undo/redo snapshot with optional History labels. Files are larger than PDN because snapshots
  are not compressed.
- Open accepts PDR, PDN, PNG, JPEG, TIFF, BMP, TGA, DDS, GIF and WebP. Flat formats open as one
  clean background layer; PDR restores the editable session and history.
- The native Save As panel lists the full supported format set in its File type popup.

## Known gaps

- Native macOS menus do not render icons.
- Menu shortcut hints only show bindings actually implemented; reference-only Image
  shortcuts remain unwired.
- Move still lacks scale/rotate handles; Anisotropic resampling is disabled.
- Layered document save, DPI/color-profile metadata and several advanced effects remain
  future work.
