# Paint.Rust 0.1.2 — installers and release automation

Status: prerelease development preview, published from the GitHub Actions installer workflow.

## Highlights

- Added a complete PDR session format (`.pdr`): layers, active layer, selection and the full
  undo/redo history, with optional History labels.
- Open now accepts PDR, PDN and the eight saved raster formats: PNG, JPEG, TIFF, BMP, TGA,
  DDS, GIF and WebP.
- Save As remains one native OS panel with an in-panel File type selector.
- Added CI/CD for unsigned development-preview installers:
  - macOS DMG and PKG;
  - Windows x86_64 NSIS setup;
  - Linux x86_64 Debian package;
  - portable ZIP/tar.gz archives from the existing verified packager.
- `main` pushes upload installer artifacts; `v*` tags publish a prerelease with assets and
  SHA-256 sidecars.

## Verification

- **619 Rust workspace tests**, 0 failures.
- Strict Clippy, `xtask verify`, macOS native gate: PASS.
- GitHub Actions CI green on macOS, Windows and Linux.
- Installer workflow green on all three platforms.
- Installers are **unsigned and unnotarized**. Windows install/launch/uninstall has not been
  exercised on a real Windows host by the maintainer; CI builds the installer.
- Portable archives retain the existing SBOM, notices, smoke evidence and verification receipt.

## Installer assets

- `Paint.Rust-0.1.2-macos-aarch64.dmg`, `.pkg`
- `Paint.Rust-0.1.2-windows-x86_64-setup.exe`
- `paint-rust_0.1.2_amd64.deb`
- Portable `paint-r-0.1.2-<platform>.zip|tar.gz` archives

## Known limitations

- No signing, notarization, Authenticode, auto-update or public-stable channel.
- macOS Apple silicon only; Windows x86_64 only; Linux x86_64 only.
- Windows byte-for-byte release reproduction is not asserted because the MSVC linker output
  differs across target directories; macOS and Linux retain the reproducibility gate.
