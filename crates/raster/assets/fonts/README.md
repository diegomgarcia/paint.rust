# Embedded fonts

The Text tool embeds the variable font files in this directory so text rendering stays
deterministic and independent of installed system fonts.

- `Roboto-Variable.ttf` and `Roboto-Italic-Variable.ttf`
- `RobotoMono-Variable.ttf` and `RobotoMono-Italic-Variable.ttf`

Both families are Copyright The Roboto Project Authors and are distributed under the
SIL Open Font License 1.1; the exact license texts are `OFL-Roboto.txt` and
`OFL-RobotoMono.txt`. They were downloaded from the Google Fonts repository:

- <https://github.com/google/fonts/tree/main/ofl/roboto>
- <https://github.com/google/fonts/tree/main/ofl/robotomono>

Only the font files and their license texts are committed; no font is copied from
Paint.NET or any other proprietary source.
